# Animation
Import model and an animation from a source, and other animations from a different source.
-	Driver code for the animation
-	Multiple animations from different sources incorporated into the one animator
-	Blending of animation via a blend tree
-	Layers on the animation allowing overlays of one animation over another EG A wave while running
-	Implement animation events to allow appropriate timing of other events based on specific parts of the animation like IE a sound being played when the animation foot hits the ground
-	Inverse kinematics using the inbuilt system and a simple overwrite from first principles
